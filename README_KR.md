# 국민연금 투자 텔레그램 봇

매일 아침 8시(KST)에 국민연금 투자 관련 리포트를 텔레그램으로 전송합니다.

## 기능

1. **국민연금 포트폴리오 요약** — 주요 보유 종목의 주간 등락률
2. **국민연금 투자 뉴스** — 네이버 뉴스 실시간 크롤링
3. **저평가 종목 발굴** — 국민연금 보유 종목 중 PER/PBR 저평가 + 거래량 감소(저관심) 종목 탐색

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env
# .env 파일에 텔레그램 봇 토큰과 채팅 ID 입력
```

## 텔레그램 봇 설정

1. [@BotFather](https://t.me/BotFather)에서 새 봇 생성 → 토큰 발급
2. 봇에게 메시지를 보낸 후, `https://api.telegram.org/bot<TOKEN>/getUpdates`에서 `chat_id` 확인
3. `.env` 파일에 입력:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   TELEGRAM_CHAT_ID=123456789
   ```

## 실행

```bash
python bot.py
```

첫 실행 시 즉시 리포트를 전송하고, 이후 매일 오전 8시에 자동 전송됩니다.

## 종목 분석 기준

| 지표 | 조건 | 점수 |
|------|------|------|
| PER | ≤ 10 | +3 |
| PER | ≤ 15 | +1 |
| PBR | ≤ 0.7 | +3 |
| PBR | ≤ 1.0 | +1 |
| 거래량 | 최근 5일 평균 < 이전 평균의 70% | +2 |
| 고점 대비 | 20% 이상 하락 | +2 |

점수 3점 이상인 종목을 상위 5개까지 추천합니다.
